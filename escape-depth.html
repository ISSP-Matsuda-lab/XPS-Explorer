計算モデル・単位・適用範囲

入力した単位胞を周期的に繰り返す、均質な結晶の平坦なスラブを扱います。面間隔d = 1/|h b* + k b* + l c*|（逆格子は2πを含まない）、各サイトの面密度は占有率 × d/Vです。整数の面指数は最大公約数で約分します。層の深さは zj,n = mod(s − h·fj, 1)d + nd。0 ≤ z < 厚さの層を足し合わせます。

Neff = Σj,n (占有率j d/V) exp[−zj,n/(λ cosθ)]。Y = σ Neff。1 Mb = 10⁻¹⁸ cm² = 10⁻⁴ nm²。情報深さ95% = −ln(0.05) λ cosθ は均質な半無限連続体の参考値で、有限の原子層に対する累積深さではありません。

TPP-2M（nm）：λ = E/{Ep²[β ln(γE) − C/E + D/E²]}、Ep = 28.816√U、U = Nvρ/M、β = −1 + 9.44/√(Ep² + Eg²) + 0.69ρ0.1、γ = 0.191ρ−0.5、C = 19.7 − 9.1U、D = 534 − 208U。

50〜2000 eVを基本範囲とし、2000〜10000 eVは非相対論式の外挿として表示します。それ以外はIMFPの手入力が必要です。本画面は指定された近似として E = hν − EB − φ をIMFPにも使います。厳密な固体内エネルギーの基準や分析器の仕事関数との違いに注意し、必要ならλを上書きしてください。

弾性散乱・光電子回折・偏光と角度非対称性・表面再構成・粗さ・多層膜の異なるIMFP・光の吸収は含みません。IMFPは実効減衰長（EAL）とは異なります。厚い試料、高い角度分解能、絶対定量には追加のモデルや校正が必要です。

結合エネルギーは既存アプリのLBNL参照値で、化学シフトはEB欄で補正します。断面積はYeh–Lindauの全サブシェル値を統計重率でスピン軌道分割し、対数空間で補間します。手入力したσは表示された1成分の値として扱います。表の「自動」は上書き値を解除します。
